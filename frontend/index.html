Apa itu port native Android?

Port native adalah versi Android dari game PC atau konsol yang dibangun ulang dari kode sumbernya — bukan dijalankan lewat emulator. Proyek seperti source port memakai ulang engine asli (misalnya id Tech atau Build), sedangkan proyek dekompilasi mengembalikan kode dari binary lalu menyusunnya ulang untuk arsitektur ARM.

Hasilnya: kontrol sentuh dan gamepad yang dapat disesuaikan untuk Android, tanpa emulasi perangkat keras. Sebagian port tetap membutuhkan berkas data dari game asli yang Anda miliki. Beberapa port bahkan menambahkan dukungan layar lebar, penyimpanan cloud, dan mod. Karena itu GamePort mencatat status kematangan setiap port — stabil, beta, eksperimental, atau alpha — beserta kebutuhan data game aslinya.

Katalog ini dikurasi manual. Setiap halaman port memuat deskripsi, cara instalasi, kebutuhan penyimpanan, porter asal, dan tautan ke sumber resminya. Semua port tetap milik pembuat aslinya.

Pertanyaan umum

Apakah port native butuh emulator?

Tidak. Port native menjalankan kode game yang sudah dikompilasi untuk Android, jadi tidak ada emulasi perangkat keras. Namun, sebagian port membutuhkan berkas data atau ROM dari game asli; kebutuhan tersebut dicantumkan di halaman masing-masing.

Apa arti status Stabil, Beta, dan Alpha?

Stabil berarti fitur utama dan penyimpanan sudah berjalan baik. Beta masih punya bug minor, eksperimental dan alpha bisa crash atau belum mendukung semua perangkat.

Kenapa ada port yang membutuhkan data game asli?

Sebagian port hanya berisi engine. Agar bisa dimainkan, Anda perlu menyalin berkas data dari game yang Anda miliki sendiri ke folder yang ditentukan. Halaman port selalu mencantumkan kebutuhan ini.

Apakah unduhan aman?

GamePort tidak mengemas ulang berkas. Tautan unduhan diarahkan ke halaman rilis porter aslinya, dan setiap halaman port mencantumkan sumber yang bisa Anda periksa.
